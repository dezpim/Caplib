# Caplib

Windows 환경에서 문서/도서 뷰어의 연속 화면을 자동으로 넘기며 캡처하고, 완료 시 즉시 ZIP 압축으로 정리해 주는 경량 포터블 유틸리티입니다.

---

## 주요 기능

1. **자동 넘김 & 스마트 로딩 캡처 (기본 모드)**
   - 지정된 횟수만큼 **우측 화살표(`VK_RIGHT`)** 키를 송출하여 다음 페이지로 넘깁니다.
   - **기본 대기 시간 (최소 딜레이)**: 넘김 후 최소 보장 대기 시간(기본 0.5초, 0.0~10.0초)을 설정합니다.
   - **스마트 로딩 감지 (화면 안정화)**:
     - 뷰어의 픽셀 변화율을 실시간 샘플링하여 로딩 스피너/애니메이션이 완전히 사라지고 본문 렌더링이 완료되는 순간을 감지합니다.
     - **시간과 스마트 로딩 동시 적용**: 기본 대기 시간(예: 0.5초) 동안 안전하게 초기 통신/전환을 보장한 뒤, 로딩 완료가 확인되는 즉시 캡처합니다. (로딩 지연 시 최대 타임아웃까지 유연하게 대기)
     - 필요에 따라 시간만 적용, 스마트 로딩만 적용, 또는 동시 적용을 자유롭게 켜고 끌 수 있습니다.
   - 시작 전 카운트다운(기본 3초)을 제공하여 대상 창을 안전하게 활성화할 수 있습니다.

2. **완료 시 자동 ZIP 압축 및 원본 정리**
   - 캡처가 완료되거나 도중 중지할 경우, 저장된 개별 이미지 파일들을 `captures/YYYYMMDD_HHmmss.zip`으로 일괄 압축합니다.
   - 압축 완료 후 임시 이미지 파일 및 세션 폴더를 자동으로 삭제하여 스토리지를 깔끔하게 유지합니다.

3. **전역 단축키 `F8` 지원**
   - 대상 뷰어 화면을 보고 있는 상태에서 언제든 **`F8`** 키를 눌러 캡처를 시작하거나 즉시 중지할 수 있습니다.

4. **수동 클릭 감지 캡처 모드**
   - 마우스 클릭(`WH_MOUSE_LL`)을 감지하여 클릭 순간 화면을 자동 저장하는 기존 수동 모드도 제공합니다. (클릭 위치 마커 옵션 지원)

5. **캡처 범위 및 포맷 설정**
   - 캡처 범위: 전체 화면(모든 모니터), 주 모니터, 활성 창
   - 저장 포맷: PNG (무손실), JPEG (용량 절약)

## 빌드 및 실행 방법

Windows 기본 탑재 .NET Framework 4.5+ C# 컴파일러를 사용하므로 별도의 IDE나 무거운 SDK 설치 없이 1초 만에 빌드됩니다.

```powershell
cd Caplib
.\build.ps1
.\Caplib.exe
```

빌드가 완료되면 폴더 내에 단일 실행 파일 `Caplib.exe`가 생성됩니다.

## 프로젝트 구조

```text
Caplib/
├── Caplib/
│   ├── build.ps1          # 빌드 스크립트 (Windows 내장 csc.exe 활용)
│   ├── Program.cs         # 애플리케이션 진입점 & DPI 인식 설정
│   ├── MainForm.cs        # UI 및 자동 넘김/루프, 스마트 로딩 감지, ZIP 압축 제어
│   ├── ScreenCapturer.cs  # 화면 캡처 및 이미지 인코딩
│   ├── NativeMethods.cs   # Windows API P/Invoke 및 키 송출/단축키
│   ├── ClickHook.cs       # 전역 마우스 저수준 훅 (수동 모드용)
│   └── captures/          # 캡처 및 압축 결과물 저장 디렉토리
├── STATUS.md              # 프로젝트 세션 상태 및 검증 내역
├── .gitignore             # Git 제외 설정
└── README.md              # 프로젝트 안내 문서
```
